FOUNDATIONS

Introduction to Machine Learning

Machine Learning (ML) is an area of Artificial Intelligence in which a system improves its performance on a task by learning from observations or experience.

Instead of manually programming every possible situation, we provide the learning system with data or feedback. The system uses this information to identify patterns and improve how it performs a task.

1.1 Traditional programming vs machine learning

01

Traditional programming

Input data + Programmed rules ↓ Output

A programmer explicitly provides the rules used to produce the output.

02

Machine learning

Training data + Learning algorithm ↓ Learned model

The algorithm uses examples to learn a model that can make predictions on new data.

1.2 Common machine learning applications

01

Email filtering

Identify whether an email is spam or not spam.

02

Weather prediction

Predict a numerical value such as temperature.

03

Customer grouping

Discover groups of similar customers.

04

Game playing

Improve actions using rewards and penalties.

IMPORTANT CONCEPT

Learning from labelled examples, discovering patterns in unlabelled data and learning through rewards are three different learning situations. They should not be confused in examination questions.

02

LEARNING PARADIGMS

Three Types of Machine Learning

The type of learning depends on the information or feedback provided to the learning system.

01

Supervised Learning

The system is given inputs together with their correct outputs.

Example Emails labelled as spam or not spam.
Does the system know the correct answer for each training example? Yes.
02

Unsupervised Learning

The system receives inputs without provided correct output labels.

Example Grouping customers into clusters.
Are correct output labels provided? No.
03

Reinforcement Learning

The system learns by acting and receiving rewards or penalties.

Example A program learns to play chess.
Does the system receive feedback after acting? Yes, through rewards or penalties.

2.1 Compare the learning types

Learning type Information received Typical task
Supervised Inputs with correct outputs. Classify an email as spam.
Unsupervised Inputs only. Group customers into clusters.
Reinforcement Reward or penalty after acting. Learn to play a game.

LABELLED TRAINING DATA

Supervised Learning

Supervised learning uses examples where the correct output is already known.

3.1 Understanding a training example

Each training example is represented as a pair:

TRAINING EXAMPLE
(x, y)

x represents a vector of input attributes, while y represents the correct output or label.

INPUT ATTRIBUTES (x)
Study hours = 8 Attendance = 90% Assignments = 85%
→
KNOWN OUTPUT (y)
Final mark = 78

3.2 The hypothesis space

In supervised learning, the learner searches a hypothesis space H for a hypothesis h that approximates the unknown function f.

HYPOTHESIS CONCEPT
h ∈ H

H is the set of possible hypotheses or models. The learner selects a hypothesis h that attempts to approximate the unknown function f.

H
HYPOTHESIS SPACE

The collection of possible models that the learning algorithm can consider.

h
HYPOTHESIS

One particular model selected from the hypothesis space.

f
UNKNOWN FUNCTION

The actual relationship the learner is attempting to approximate.

3.3 What does it mean for a hypothesis to be consistent?

A hypothesis h is consistent if it gives the correct output for every training example.

IMPORTANT EXAM DEFINITION

Consistency means zero error on the training examples. It does not automatically mean that the hypothesis will predict unseen examples accurately.

MODEL EVALUATION

Training Data, Test Data and Generalisation

A model must be evaluated using data it has not previously seen. Correct predictions on training examples alone are not enough.

5.1 Training set

The training set contains examples used by the learning algorithm to learn the model.

5.2 Test set

The test set contains data the model has not seen during training. It is used to assess how accurately the model predicts unseen data.

TRAINING SET Learn the model

Examples used during learning.

→
LEARNED MODEL Hypothesis h

Approximates the unknown function f.

→
TEST SET Evaluate predictions

Unseen examples used for evaluation.

5.3 Generalisation

A model generalises well when it makes accurate predictions on data that was not used to train it.

EXAM CONCEPT

A hypothesis can be perfectly consistent with the training set and still perform badly on the test set. Training performance does not guarantee good generalisation.

06

MODEL COMPLEXITY

Bias and Variance

Bias and variance describe two different ways in which a learning model can perform poorly.

01

Bias

Bias occurs when the hypothesis systematically deviates from the true function.

Often associated with underfitting.
  • Model is too restricted.
  • Fails to capture patterns in the data.
  • Example: using a straight line for a wavy function.
02

Variance

Variance describes how much the learned hypothesis changes when the training data changes.

Often associated with overfitting.
  • Model is too flexible.
  • Fits training examples too closely.
  • Example: a degree-12 polynomial fitted to 13 points.

6.1 Underfitting

Underfitting occurs when the model is too simple to represent the patterns in the data. A straight line may fail to describe a wavy relationship even when more data is available.

6.2 Overfitting

Overfitting occurs when a model fits the training examples too closely. It may perform very well on training data but poorly on unseen data.

6.3 Model complexity and error

As model complexity increases, training error keeps falling. Validation error initially falls and then rises. The preferred model complexity is where validation error is lowest.

MODEL COMPLEXITY

Training error vs validation error

MODEL BEHAVIOUR Balanced model

Move the slider to examine how model complexity changes the behaviour of training and validation error.

6.4 Choosing a model

If two hypotheses fit the data equally well, prefer the simpler hypothesis. This is the principle of Ockham's razor.

EXAM COMPARISON

A straight line fitted to a wavy function has high bias and underfits. A degree-12 polynomial fitted to 13 points has high variance and may overfit.

CLASSIFICATION EVALUATION

Confusion Matrix: TP, FP, FN and TN

A confusion matrix compares the model's predicted class with the actual class. For a two-class classifier, there are four possible outcomes.

7.1 The confusion matrix

Model prediction Actual class
Positive Negative
Predicted positive True Positive (TP) Correct positive prediction False Positive (FP) Incorrect positive prediction
Predicted negative False Negative (FN) Incorrect negative prediction True Negative (TN) Correct negative prediction

7.2 Understanding the four outcomes

TP True Positive

Model predicts positive and the actual class is positive.

FP False Positive

Model predicts positive but the actual class is negative.

FN False Negative

Model predicts negative but the actual class is positive.

TN True Negative

Model predicts negative and the actual class is negative.

NEURAL NETWORK FUNDAMENTALS

How a Single Neuron Works

A single neuron multiplies each input by its corresponding weight, adds the weighted inputs and passes the resulting sum through an activation function.

8.1 Weighted inputs

Suppose there are four inputs and four weights. Each input contributes according to its corresponding weight.

WEIGHTED SUM
z = Σ (xi × wi)

x represents an input value and w represents its corresponding weight. The sum of all input-weight products is the weighted sum, also called the net input.

8.2 Activation function

The weighted sum is passed through an activation function. The supplied lecture code uses NumPy's heaviside function.

HEAVISIDE ACTIVATION
a = heaviside(z, 1)

In the supplied example, the weighted sum is positive, so the activation output is 1.0.

8.3 Worked calculation from the guide

INPUTS [0.15, 0.5, 0.7, 0.22]
WEIGHTS [0.22, 0.27, 0.72, 0.05]
PYTHON SINGLE NEURON 
import numpy as np

inputs = [0.15, 0.5, 0.7, 0.22]

weights = [0.22, 0.27, 0.72, 0.05]

weighted_inputs = np.multiply(inputs, weights)

soma = np.sum(weighted_inputs)

activation = np.heaviside(soma, 1)

print(activation)

8.4 Step-by-step calculation

Input Weight Multiplication Result
0.15 0.22 0.15 × 0.22 0.033
0.5 0.27 0.5 × 0.27 0.135
0.7 0.72 0.7 × 0.72 0.504
0.22 0.05 0.22 × 0.05 0.011
SUM THE PRODUCTS
z = 0.033 + 0.135 + 0.504 + 0.011
z = 0.683

Since 0.683 is greater than zero, the Heaviside activation returns 1.

Output = 1.0

Min-Max Scaling

Min-max scaling transforms a feature to the range from 0 to 1. It allows values measured on different scales to be compared.

9.1 Formula

MIN-MAX SCALING
xscaled = (x − minimum) / (maximum − minimum)

x is the original value. Minimum and maximum are the smallest and largest values in the feature's range.

9.2 Worked example: speed

Scale a speed of 40 mph when the range is from 0 to 70 mph.

Step 1: Substitute into the formula
(40 − 0) / (70 − 0)
Step 2: Calculate
40 / 70 = 0.5714
Final answer: approximately 0.57.

9.3 Worked example: distance

Scale a distance of 50 thousand miles when the range is from 0 to 300 thousand miles.

Step 1: Substitute
(50 − 0) / (300 − 0)
Step 2: Calculate
50 / 300 = 0.1667
Final answer: approximately 0.17.

BACKGROUND

Neural Network History

1958

Perceptron — Frank Rosenblatt

The perceptron was introduced. A single perceptron can learn linearly separable problems.

1969

Minsky and Papert

Their work showed that a single perceptron cannot learn XOR.

1980s

Multi-layer networks and backpropagation

Multi-layer networks trained with backpropagation overcame the single-layer perceptron's limitation.

10.1 Why is XOR important?

A single perceptron separates classes using a single straight-line decision boundary. XOR cannot be separated by one straight line.

XOR input

x1 x2 Output
000
011
101
110
Why one line is not enough

The positive outputs are at (0,1) and (1,0). The negative outputs are at (0,0) and (1,1).

No single straight line separates the two classes.

A hidden layer is needed.

11.3 Cost and gradient descent

COST FOR ONE EXAMPLE
C = 0.5 × (ŷ − y)²

Example: prediction ŷ = 0.664, target y = 1 → C = 0.5 × (0.664 − 1)² = 0.5 × 0.1129 ≈ 0.056.

GRADIENT DESCENT
W ← W − α∇C(W)

Step each weight against the slope of the cost, with learning rate α. Backpropagation pushes the error back through the layers to get each weight's gradient. Counting weights: 4 inputs fully connected to 14 hidden units give 4 × 14 = 56 weights into the hidden layer.

Line-fitting update (caterpillars vs ladybirds)

The slope is updated by Δm = L · E / x. With m = 0.25, learning rate L = 0.5, x = 3.0 and error E = 0.35: Δm = 0.5 × 0.35 / 3.0 ≈ 0.0583, so the new slope is m = 0.3083.

11.4 Network types and history

Recurrent networks (RNN)

Have loops, so earlier outputs feed back in. They suit sequences such as text or speech.

Convolutional networks (CNN)

Use local receptive fields that scan small patches. They suit images.

Linear separability

A single perceptron can only separate classes with one line or hyperplane. That is why XOR fails.

Question 4 — Consistency

A hypothesis has zero error on the training set. Which statement must be true?

  1. It will predict the test set well.
  2. It is consistent with the training set.
  3. It is the simplest hypothesis.
  4. It has low variance.
Show answer

B. Zero training error means the hypothesis is consistent with the training set.

Nothing necessarily follows about its test performance, simplicity or variance.

Question 5 — Bias and variance

A straight line and a degree-12 polynomial are fitted to 13 points from a wavy function. Which has high bias and which has high variance?

Show answer

The straight line has high bias and underfits because it cannot represent the wavy relationship.

The degree-12 polynomial has high variance and may overfit by fitting the training points too closely.

Question 9 — XOR and the perceptron

Why can a single perceptron not learn XOR?

Show answer

A single perceptron creates a linear decision boundary. XOR is not linearly separable, so one straight line cannot separate its positive and negative classes. A hidden layer is needed.
