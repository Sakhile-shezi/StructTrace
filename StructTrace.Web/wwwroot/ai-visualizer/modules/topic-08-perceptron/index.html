NEURAL NETWORK FOUNDATIONS

What is a Perceptron?

A perceptron is a simple artificial neuron that receives input values, multiplies them by weights, adds a bias and produces an output using an activation function.

During training, the perceptron compares its predicted output with the target output. When they differ, the weights and bias are adjusted so that the neuron can improve its predictions.

1.1 Structure of a perceptron

Inputs are weighted, summed with the bias, and passed through the activation function.

1.2 Components of the perceptron

01

Inputs (x)

The values supplied to the perceptron, such as x1, x2 and x3.

02

Weights (w)

Values that determine the influence of each input.

03

Bias (b)

An additional value added to the weighted input sum.

04

Activation

Converts the net input into the perceptron's predicted output.

1.3 Important training terminology

Term Meaning
Input (x) One feature value supplied to the perceptron.
Target (t) The correct output expected for the training example.
Net input (y_in) The bias plus the sum of input-weight products.
Output (y) The result produced by the threshold activation.
Learning rate (α) Controls the size of the weight and bias adjustments.
Epoch One complete pass through all training rows.
Convergence Training has reached an epoch with no weight changes.

EXAM FORMULA SHEET

Important Perceptron Formulas

These formulas are the foundation of every perceptron training table in your COMP304 guide.

2.1 Net input / weighted sum

FORMULA 1 — NET INPUT
yin = b + Σ (xi × wi)
yin = b + x1w1 + x2w2 + ... + xnwn

Always include the bias first. Then multiply each input by its matching weight and add all the products.

2.2 Weight update

FORMULA 2 — WEIGHT UPDATE
wi(new) = wi(old) + α × t × xi

Update each weight only when the predicted output differs from the target.

2.3 Bias update

FORMULA 3 — BIAS UPDATE
b(new) = b(old) + α × t

The bias is updated using the learning rate and the target. It is not a weight that should be forgotten during the calculation.

2.4 Weight correction

FORMULA 4 — CHANGE IN WEIGHT
Δwi = α × t × xi
Δb = α × t

Calculate the corrections first, then add them to the old weights and bias.

2.5 Decision rule

FORMULA 5 — PREDICTED OUTPUT
1 if yin is greater than θ
0 if yin equals θ
−1 if yin is less than θ

2.6 The complete training rule

WHEN y = t

Correct prediction. Keep all weights and bias unchanged.

WHEN y ≠ t

Incorrect prediction. Update every weight and the bias.

EXAM WARNING

Your guide uses bipolar targets: +1 and −1. Therefore, an output of 0 is not equal to either target. It always causes an update.

2.7 Symbols you must know

Symbol Meaning

wᵢWeight associated with input i.

Threshold Activation Function

After calculating the net input, the perceptron compares it with the threshold θ to determine its predicted output.

3.1 The three possible outputs

y_in > θ Output = +1

The net input is above the threshold.

y_in = θ Output = 0

The net input is exactly at the threshold.

y_in < θ Output = −1

The net input is below the threshold.

LEARNING RULE

How to Update Weights and Bias

When a perceptron predicts incorrectly, its weights and bias are adjusted using the learning rule.

4.1 Understand the learning rate

The learning rate α controls the size of the adjustment. In the worked examples from your guide, the learning rate is α = 1.

4.2 Step-by-step weight update

GIVEN VALUES
Old weightw = 2
Inputx = −1
Targett = −1
Learning rateα = 1
STEP 1 — CALCULATE THE CHANGE
Δw = α × t × x
Δw = 1 × (−1) × (−1) = +1
STEP 2 — UPDATE THE WEIGHT
w(new) = w(old) + Δw
w(new) = 2 + 1 = 3
New weight = 3

4.3 Step-by-step bias update

GIVEN VALUES
Old biasb = 1
Targett = −1
Learning rateα = 1
STEP 1 — CALCULATE THE CHANGE
Δb = α × t = 1 × (−1) = −1
STEP 2 — UPDATE THE BIAS
b(new) = b(old) + Δb
b(new) = 1 − 1 = 0
New bias = 0

4.4 What happens when the prediction is correct?

EXAMPLE y = −1, t = −1

Prediction matches the target. No calculation or update is necessary.

EXAMPLE y = 0, t = −1

Prediction does not match the target. Calculate Δw and Δb and update.

4.5 Interactive weight-update calculator

WEIGHT AND BIAS UPDATE CALCULATE EACH CORRECTION
Calculate the new weight and bias.
COMMON EXAM MISTAKE

Calculate Δw using the target multiplied by the input. Do not accidentally use the predicted output instead of the target.

5.6 What you should learn from the example

  1. Always use the most recently updated weights for the next row.
  2. Update weights immediately after an incorrect prediction.
  3. Keep the weights and bias unchanged when the prediction is correct.
  4. Do not stop just because the last row of an epoch was correct.
  5. Check whether the entire epoch produced zero updates.

PYTHON PROGRAMMING

Implementing the Perceptron in Python

Your guide asks you to write a Python function that performs one perceptron training step. It receives the weights, bias, input vector, target and learning rate.

11.1 One training step

PYTHON TRAIN_STEP() 
def train_step(w, b, x, t, alpha=1):

    # Step 1: Calculate net input.
    # Always include the bias first.
    y_in = b

    for i in range(len(x)):
        y_in += x[i] * w[i]

    # Step 2: Apply threshold activation.
    if y_in > 0:
        y = 1
    elif y_in == 0:
        y = 0
    else:
        y = -1

    # Step 3: Update only when prediction is wrong.
    if y != t:

        for i in range(len(w)):
            w[i] = w[i] + alpha * t * x[i]

        b = b + alpha * t

    # Step 4: Return updated weights and bias.
    return w, b

11.2 Understand the code line by line

y_in = b

Begin the net input with the bias.

y_in += x[i] * w[i]

Multiply each feature by its corresponding weight and add the result.

if y_in > 0

Produce +1 when net input is positive.

elif y_in == 0

Produce 0 when net input equals the threshold.

else

Produce −1 when net input is negative.

if y != t

Update only when the predicted output differs from the target.

w[i] = w[i] + alpha * t * x[i]

Apply the perceptron learning rule to every weight.

b = b + alpha * t

Adjust the bias.

11.3 Training through multiple epochs

PYTHON TRAIN UNTIL CONVERGENCE 
def train_perceptron(data, number_of_features,
                     alpha=1, max_epochs=100):

    w = [0] * number_of_features
    b = 0

    for epoch in range(max_epochs):

        updates = 0

        for x, t in data:

            old_w = w.copy()
            old_b = b

            w, b = train_step(
                w, b, x, t, alpha
            )

            if w != old_w or b != old_b:
                updates += 1

        print(
            "Epoch:", epoch + 1,
            "Weights:", w,
            "Bias:", b,
            "Updates:", updates
        )

        if updates == 0:
            print("Training converged.")
            break

    return w, b

11.4 Important Python details

Code Purpose Common mistake
len(x) Number of input features. Using the wrong number of weights.
w.copy() Preserve old weights for comparison. Using old_w = w, which refers to the same list.
enumerate() Iterate through features with their indices. Using an incorrect index.
break Stop training when an epoch has no changes. Stopping immediately after one correct row.

11.5 Optional test function

PYTHON PREDICT A NEW INPUT 
def predict(w, b, x):

    y_in = b

    for i in range(len(x)):
        y_in += x[i] * w[i]

    if y_in > 0:
        return 1

    elif y_in == 0:
        return 0

    else:
        return -1

LIMITATIONS

Why a Single Perceptron Cannot Learn XOR

A single perceptron creates a linear decision boundary. It can separate classes that are linearly separable, but XOR is not linearly separable.

12.1 XOR truth table

x1 x2 Output Class
000Negative
011Positive
101Positive
110Negative

12.2 Visualising the XOR points

Positive class (1) Negative class (0)

12.3 Why is XOR impossible for a single perceptron?

  1. The positive points are (0,1) and (1,0).
  2. The negative points are (0,0) and (1,1).
  3. The positive and negative points occupy opposite corners.
  4. No single straight-line boundary separates the two classes.
EXAM ANSWER

XOR is not linearly separable. A single perceptron uses one linear decision boundary, so it cannot learn XOR. A multi-layer network with a hidden layer is needed.
