Stacks (LIFO), Queues (FIFO) & Deques

Enforce strict entry and exit rules on linear collections to guarantee O(1) insertions, removals, and boundary inspections without shifting elements.

2. Complexity Cheat Sheet

Structure Ordering Rule Core Operations Insert / Remove Peek Search Space
Stack LIFO (Last-In, First-Out) push, pop, peek O(1) O(1) O(n) O(n)
Queue FIFO (First-In, First-Out) enqueue, dequeue, peek O(1) O(1) O(n) O(n)
Deque Double-Ended Access addFirst, addLast, removeFirst, removeLast O(1) (amortized array) O(1) O(n) O(n)

Backing Implementation Choice: A singly linked list with head and tail backs a standard Queue in strict O(1) worst-case time, whereas a Deque requires either a doubly linked list or a circular array buffer (java.util.ArrayDeque) to remove from both ends in O(1).

3. Step-by-Step Pseudocode & Operation Log

Linked Queue: Enqueue & Dequeue

Pre: queue has head & tail pointers (both null when empty).

Post: Enqueue appends at tail; Dequeue removes and returns head.data.

Enqueue(queue, value)
    node ← new Node(value)
    if queue.tail == null then
        queue.head ← node
        queue.tail ← node
    else
        queue.tail.next ← node
        queue.tail ← node
    queue.size ← queue.size + 1

Dequeue(queue)
    if queue.head == null then
        error "Queue Underflow"
    value ← queue.head.data
    queue.head ← queue.head.next
    if queue.head == null then
        queue.tail ← null
    queue.size ← queue.size - 1
    return value

4. Java Implementation: Custom LinkedQueue vs. Built-in ArrayDeque

import java.util.NoSuchElementException;

public class LinkedQueue {
    private static class Node {
        E data;
        Node next;

        Node(E data) {
            this.data = data;
        }
    }

    private Node head;
    private Node tail;
    private int size = 0;

    public void enqueue(E value) {
        Node node = new Node<>(value);
        if (tail == null) {
            head = tail = node;
        } else {
            tail.next = node;
            tail = node;
        }
        size++;
    }

    public E dequeue() {
        if (head == null) {
            throw new NoSuchElementException("Queue Underflow: queue is empty");
        }
        E value = head.data;
        head = head.next;
        if (head == null) {
            tail = null; // Prevent dangling tail reference
        }
        size--;
        return value;
    }

    public E peek() {
        if (head == null) {
            throw new NoSuchElementException("Queue is empty");
        }
        return head.data;
    }

    public boolean isEmpty() {
        return size == 0;
    }

    public int size() {
        return size;
    }
}
import java.util.ArrayDeque;
import java.util.Deque;

public class BuiltInDequeDemo {
    public static void main(String[] args) {
        // 1. Stack (LIFO) — prefer ArrayDeque over legacy synchronized java.util.Stack
        Deque stack = new ArrayDeque<>();
        stack.push("Frame 1");
        stack.push("Frame 2");
        String topFrame = stack.pop(); // "Frame 2"

        // 2. Queue (FIFO)
        Deque queue = new ArrayDeque<>();
        queue.offerLast("Task A");
        queue.offerLast("Task B");
        String nextTask = queue.pollFirst(); // "Task A" (returns null if empty)

        // 3. Double-Ended Queue (Deque)
        Deque deque = new ArrayDeque<>();
        deque.addFirst(10);
        deque.addLast(20);
        int front = deque.removeFirst(); // 10
        int back = deque.removeLast();   // 20
    }
}
