Binary Min-Heaps & Array Index Mapping

Store a complete binary tree inside a contiguous zero-indexed array with zero node pointers, maintaining parent ≤ children for O(1) minimum lookup and O(log n) insertion and extraction.

1. Intuition & Dual Tree / Array Visualizer

Because a binary heap is always a complete binary tree, every node at index i locates its relatives via pure arithmetic: parent = ⌊(i - 1) / 2⌋, left = 2i + 1, and right = 2i + 2. Click any array cell to inspect its index relationships.

2. Complexity Cheat Sheet

Operation Time Complexity Mechanism
peekMin() O(1) Direct read at array index 0
insert(val) O(log n) Append at index size, then sift-up toward root
extractMin() O(log n) Move last element to index 0, then sift-down (MinHeapify)
buildHeap(arr) O(n) Bottom-up MinHeapify from index ⌊n/2⌋ - 1 down to 0
Search arbitrary key O(n) Siblings are unordered; requires level-pruned linear scan
Auxiliary Space O(n) Contiguous dynamic array (zero pointer overhead)

Why buildHeap is O(n) instead of O(n log n): Half of all nodes in a complete binary tree are leaves (height 0, requiring 0 swaps), a quarter sit at height 1 (at most 1 swap), and only the single root sifts down log2 n levels—summing to at most 2n operations.

3. Step-by-Step Pseudocode & Sift Trace Log

ExtractMin & SiftDown (MinHeapify)

Pre: H is a valid min-heap array of size n ≥ 1.

Post: Removes and returns H[0], restoring parent ≤ children.

ExtractMin(H)
    if H.size == 0 then
        error "Heap Underflow"
    minVal ← H[0]
    H[0] ← H[H.size - 1]
    H.size ← H.size - 1
    if H.size > 0 then
        SiftDown(H, 0)
    return minVal

SiftDown(H, i)
    while (2 * i + 1) < H.size do
        left ← 2 * i + 1
        right ← 2 * i + 2
        smallest ← left

        if right < H.size and H[right] < H[left] then
            smallest ← right
        if H[i] ≤ H[smallest] then
            break

        swap(H[i], H[smallest])
        i ← smallest

4. Java Implementation: Custom MinHeap vs. Built-in PriorityQueue

import java.util.ArrayList;
import java.util.NoSuchElementException;

public class MinHeap> {
    private final ArrayList heap = new ArrayList<>();

    public void insert(E value) {
        if (value == null) {
            throw new IllegalArgumentException("Null values are not permitted");
        }
        heap.add(value);
        siftUp(heap.size() - 1);
    }

    public E extractMin() {
        if (heap.isEmpty()) {
            throw new NoSuchElementException("Heap Underflow: heap is empty");
        }
        E min = heap.get(0);
        E last = heap.remove(heap.size() - 1);
        if (!heap.isEmpty()) {
            heap.set(0, last);
            siftDown(0);
        }
        return min;
    }

    public E peekMin() {
        if (heap.isEmpty()) {
            throw new NoSuchElementException("Heap is empty");
        }
        return heap.get(0);
    }

    private void siftUp(int i) {
        while (i > 0) {
            int parent = (i - 1) / 2;
            if (heap.get(i).compareTo(heap.get(parent)) >= 0) {
                break;
            }
            swap(i, parent);
            i = parent;
        }
    }

    private void siftDown(int i) {
        int n = heap.size();
        while (2 * i + 1 < n) {
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            int smallest = left;

            if (right < n && heap.get(right).compareTo(heap.get(left)) < 0) {
                smallest = right;
            }
            if (heap.get(i).compareTo(heap.get(smallest)) <= 0) {
                break;
            }
            swap(i, smallest);
            i = smallest;
        }
    }

    private void swap(int i, int j) {
        E temp = heap.get(i);
        heap.set(i, heap.get(j));
        heap.set(j, temp);
    }

    public int size() {
        return heap.size();
    }
}
import java.util.Collections;
import java.util.PriorityQueue;

public class BuiltInPriorityQueueDemo {
    public static void main(String[] args) {
        // 1. Default Min-Heap (natural ordering)
        PriorityQueue minHeap = new PriorityQueue<>();
        minHeap.offer(25); // O(log n)
        minHeap.offer(10); // O(log n)
        minHeap.offer(15); // O(log n)

        int peeked = minHeap.peek(); // O(1) -> 10
        int min = minHeap.poll();    // O(log n) -> removes and returns 10

        // 2. Max-Heap variant using Collections.reverseOrder()
        PriorityQueue maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        maxHeap.offer(25);
        maxHeap.offer(10);
        maxHeap.offer(15);

        int max = maxHeap.poll();    // O(log n) -> removes and returns 25
    }
}
