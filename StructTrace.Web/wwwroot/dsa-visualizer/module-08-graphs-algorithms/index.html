2. Graph & Sorting Complexity Cheat Sheet

Algorithm / Representation Best Case Average Case Worst Case Auxiliary Space Key Property
Adjacency List (Map>) Edge check: O(deg(v)) • Iterate neighbors: O(deg(v)) O(V + E) Optimal for sparse real-world graphs
Adjacency Matrix (int[V][V]) Edge check: O(1) • Iterate neighbors: O(V) O(V²) Fast edge lookup; costly memory for large V
BFS & DFS Traversal O(V + E) O(V + E) O(V + E) O(V) BFS finds unweighted shortest paths
Dijkstra's Algorithm (Min-Heap) O(E log V) O(E log V) O(E log V) O(V) Requires non-negative edge weights (w ≥ 0)
Insertion Sort O(n) O(n²) O(n²) O(1) Stable; fastest on tiny or nearly sorted arrays
Merge Sort O(n log n) O(n log n) O(n log n) O(n) Stable; guaranteed O(n log n) worst-case
Quick Sort O(n log n) O(n log n) O(n²) O(log n) stack Unstable; in-place with superior cache locality

How Java's Arrays.sort() Chooses: For primitive arrays (int[]), Java uses Dual-Pivot Quicksort (fast in-place, stability irrelevant for equal primitives). For object arrays (T[]) and List.sort(), Java uses TimSort (a hybrid Merge + Insertion Sort) to guarantee O(n log n) worst-case time and preserve stability.

3. Step-by-Step Pseudocode & Execution Log

Dijkstra's Shortest Path (Min-Heap)

Pre: Weighted graph G = (V, E) with non-negative weights w(u, v) ≥ 0; source s.

Post: Computes shortest distance dist[v] and predecessor prev[v] for every reachable vertex v.

Dijkstra(G, s)
    for each vertex v in G.V do
        dist[v] ← ∞
        prev[v] ← null
    dist[s] ← 0

    pq ← new MinPriorityQueue()
    pq.insert((0, s))

    while not pq.isEmpty() do
        (d, u) ← pq.extractMin()
        if d > dist[u] then
            continue // Skip stale queue entry

        for each edge (u, v, weight) in G.adj[u] do
            if dist[u] + weight < dist[v] then
                dist[v] ← dist[u] + weight
                prev[v] ← u
                pq.insert((dist[v], v))

4. Java Implementation: Custom WeightedGraph vs. Built-in Sorting & Comparators

import java.util.*;

public class WeightedGraph {
    public record Edge(V target, int weight) {}
    private record NodeDist(V vertex, int dist) implements Comparable> {
        @Override
        public int compareTo(NodeDist other) {
            return Integer.compare(this.dist, other.dist);
        }
    }

    private final Map>> adj = new HashMap<>();

    public void addVertex(V v) {
        adj.putIfAbsent(v, new ArrayList<>());
    }

    public void addUndirectedEdge(V u, V v, int weight) {
        addVertex(u);
        addVertex(v);
        adj.get(u).add(new Edge<>(v, weight));
        adj.get(v).add(new Edge<>(u, weight));
    }

    public List bfs(V start) {
        List order = new ArrayList<>();
        if (!adj.containsKey(start)) return order;

        Set visited = new HashSet<>();
        Queue queue = new ArrayDeque<>();

        visited.add(start);
        queue.offer(start);

        while (!queue.isEmpty()) {
            V curr = queue.poll();
            order.add(curr);
            for (Edge edge : adj.get(curr)) {
                if (visited.add(edge.target())) {
                    queue.offer(edge.target());
                }
            }
        }
        return order;
    }

    public Map dijkstra(V start) {
        Map dist = new HashMap<>();
        for (V v : adj.keySet()) {
            dist.put(v, Integer.MAX_VALUE);
        }
        dist.put(start, 0);

        PriorityQueue> pq = new PriorityQueue<>();
        pq.offer(new NodeDist<>(start, 0));

        while (!pq.isEmpty()) {
            NodeDist current = pq.poll();
            V u = current.vertex();
            if (current.dist() > dist.get(u)) continue; // Stale entry

            for (Edge edge : adj.get(u)) {
                int newDist = dist.get(u) + edge.weight();
                if (newDist < dist.get(edge.target())) {
                    dist.put(edge.target(), newDist);
                    pq.offer(new NodeDist<>(edge.target(), newDist));
                }
            }
        }
        return dist;
    }
}
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;

public class BuiltInSortingDemo {
    record Student(String name, double gpa) {}

    public static void main(String[] args) {
        // 1. Primitive array: Dual-Pivot Quicksort O(n log n) avg, O(1) space
        int[] nums = {38, 14, 52, 9, 41, 23};
        Arrays.sort(nums); // [9, 14, 23, 38, 41, 52]

        // 2. Object List: TimSort (Stable Merge + Insertion Sort) O(n log n) worst-case
        List students = new ArrayList<>(List.of(
            new Student("Cleo", 3.9),
            new Student("Alice", 3.9),
            new Student("Bob", 3.5)
        ));

        // Sort by GPA descending, then alphabetically by name
        students.sort(
            Comparator.comparingDouble(Student::gpa).reversed()
                      .thenComparing(Student::name)
        );
    }
}
